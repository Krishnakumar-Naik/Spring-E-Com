# Spring ECom

The frontend project is in the `frontend` folder.

To run it locally:

```sh
npm install
```

Set `VITE_BASE_URL` in `frontend/.env` to the address of your Spring Boot backend, then start the frontend:

```sh
npm run dev
```

# SpringEcom Backend

This folder contains the backend service for the Spring E-commerce application.

## Overview

- Java 21
- Spring Boot 4
- Spring Web MVC
- Spring Data JPA
- PostgreSQL

## Prerequisites

- Java 21 or later
- Maven or the included Maven wrapper
- PostgreSQL running on `localhost:5432`

## Configuration

Update the database settings as needed for your local environment.


## Project structure

```text
src/
  main/
    java/
    resources/
  test/
```

## Notes

This backend is designed to serve the e-commerce APIs and connect to PostgreSQL for persistence.
