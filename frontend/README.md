# Spring ECom

This repository contains the frontend for the Spring ECom store. The app is built with React and Vite and uses a Spring Boot API.

## Run it locally

Install the packages:

```sh
npm install
```

Set `VITE_BASE_URL` in `.env` to the address of the backend. For a local backend, use `http://localhost:8080`. Then start the app:

```sh
npm run dev
```

The development server prints the local address when it starts.
